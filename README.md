## About the Project

Charlal is a marketplace platform where users can create listings, browse products and services, discover job opportunities or events, and communicate with other users.

## Features

- User authentication
- Create and manage listings
- Search and categories
- Buyer/seller messaging
- Image uploads
- Responsive design

## Tech Stack

- Next.js
- React
- TypeScript
- Supabase
- PostgreSQL
- CSS

## What I Learned

- Building a full-stack application with Next.js and TypeScript
- Managing authentication and database permissions with Supabase
- Designing user flows for marketplace features
- Debugging complex frontend and backend interactions

## Project Status

Currently in active development.

Completed:
- User authentication
- Listings

- Image uploads

Planned:
- Notifications

- Additional marketplace improvements



## Development Approach

This project was developed using AI-assisted workflows for exploration, debugging and productivity. AI suggestions were reviewed, tested, modified, and integrated as part of an iterative development process.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
